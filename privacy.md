# Privacy Policy for SM Type Test

**Effective Date:** November 8, 2026

**1. No Accounts and No Tracking**
SM Type Test is designed with strict respect for your privacy. The application does not require user accounts or logins. It contains absolutely no telemetry, analytics, or usage tracking. 

**2. Local Data Storage**
All typing test results, custom exam settings, and user-provided hardcopy passages remain strictly on your device. This data is stored locally in the `~\.smtt` and `%LOCALAPPDATA%\smttms` directories. Your data is never uploaded, transmitted, or made accessible to the developer or any third party.

**3. Network Usage**
The application only connects to the internet (specifically to `github.com` and `bonanto.github.io`) to look for and download practice passages, spelling dictionaries, and OCR language packs. 

When the application makes these requests, GitHub receives standard web connection data, including your IP address and a user agent string that identifies the app version. This is an unavoidable part of any web request. This data is processed under GitHub’s privacy policy; it is never received, logged, or stored by the developer of this application.

**4. Application Updates**
Update behavior depends on which edition of the software you are using:
* **Standalone Edition:** Periodically contacts GitHub to check for and download new application updates.
* **Microsoft Store Edition:** Application updates are handled entirely by the Microsoft Store infrastructure.

**5. Contact**
If you have any questions about this privacy policy, please contact bonanto18@protonmail.com
