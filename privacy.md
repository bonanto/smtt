# Privacy Policy for SM Type Test

**Effective Date:** November 8, 2026

## 1. Introduction and Core Philosophy
SM Type Test ("the Application") is a professional desktop typing practice and evaluation tool developed by Bonanto. This Privacy Policy outlines our data handling practices. Our architectural philosophy is strictly offline-first and privacy-centric: the Application is designed to function locally on your device without harvesting, transmitting, or monetizing your personal information.

## 2. No Accounts, No Tracking, No Telemetry
We believe your practice sessions are entirely your own business. 
* **No Accounts:** The Application does not require, request, or support user account creation or social logins.
* **No Telemetry:** The Application contains absolutely no analytics, usage tracking, background telemetry, or automated crash reporting. We do not monitor how often you use the app, what you type, or how fast you type.

## 3. Local Data Storage
All data generated by your use of the Application is stored strictly and exclusively on your local device. 
* **What is stored:** Your typing test results, historical progress graphs, custom exam profiles, scoring rules, hardcopy passages, application settings, and locally processed OCR (Optical Character Recognition) data.
* **Where it is stored:** This data is maintained safely within your user profile, specifically in the `~\.smtt` and `%LOCALAPPDATA%\smttms` directories.
* **Data Ownership:** This local data is never uploaded to external servers, transmitted to the developer, or made accessible to any third party. You maintain absolute control over it. 
* **Data Deletion:** You may permanently erase all your user data at any time simply by deleting the `~\.smtt` and `%LOCALAPPDATA%\smttms` folders from your system.

## 4. Network Usage and Third-Party Connections
While the Application is primarily an offline tool, it requires limited internet connectivity to fetch specific functional assets. The Application only connects to GitHub (`github.com` and `bonanto.github.io`) to:
1. Look for and download new practice passages.
2. Download spelling dictionaries (Hunspell).
3. Fetch OCR language packs (Tesseract) for Hardcopy mode.

**What data is exposed during these connections?**
When the Application initiates these downloads, GitHub's servers inherently receive standard network connection data required to complete any web request. This includes your IP address and a User-Agent string (which identifies the Application's current version). 

**Data Processing:** This standard web traffic is processed entirely under GitHub’s privacy policy. **The developer of SM Type Test does not receive, log, access, or store this IP or User-Agent data.**

## 5. Application Updates
How the Application handles updates depends entirely on which edition of the software you have installed:
* **Standalone Edition:** The Application will periodically contact GitHub to check for, and download, new application version updates.
* **Microsoft Store Edition:** The Application itself does not check for software updates. All application updates, delivery, and installation are handled entirely by the native Microsoft Store infrastructure and its associated privacy terms.

## 6. Third-Party Components
The Application utilizes established open-source components, including Tesseract OCR, Qt/PySide6, and the Python runtime. These components execute locally on your machine and do not independently transmit your personal data.
